# Техническая информация

## Запуск Unreal MCP (UE 5.8)

В Unreal Editor открыть **Tools → Debug → Output Log** и выполнить в консольной строке:

```text
ModelContextProtocol.StartServer 18081
```

**18081** — выбранный порт MCP-сервера; локальный адрес: `http://127.0.0.1:18081/mcp`. При ручном запуске после перезапуска Unreal команду необходимо повторить. Прокси и файлы движка не изменяются.

## Плагины для подключения

В **Edit → Plugins** включить:

- **Unreal MCP** — MCP-сервер редактора для внешнего клиента.
- **All Toolsets** — инструменты редактора, в том числе для чтения выделенных акторов.

**MCP Client Toolset** — необязательный плагин для обратного направления: когда сам Unreal подключается к внешним MCP-серверам. Для чтения выделения из ChatGPT он не нужен.

После включения плагинов перезапустить Unreal, если редактор попросит, и снова выполнить `ModelContextProtocol.StartServer 18081`.
